5.6 — Accordion

FAQ sem caixa pesada

Cada item é um details nativo, separado por hairlines. Respostas curtas, sem jargão.

Onde sua operação perde tempo hoje?
Em três lugares recorrentes: atendimento de primeiro nível, consolidação de dados entre sistemas e geração de relatórios para liderança. O diagnóstico gratuito da Nexus AI mapeia o seu fluxo em uma sessão.
Em quanto tempo vejo resultado?
Em 30 dias o primeiro agente entra em produção assistida. Em 90 dias medimos o tempo devolvido ao time. Trabalhamos com janelas curtas e metas verificáveis.
A stack é aberta ou exige lock-in?
Stack aberta, sem lock-in. Os agentes rodam em contêineres seus, com logs e webhooks abertos. Se você quiser desligar, basta parar o contêiner.
Como funciona o diagnóstico antes da proposta?
Uma sessão de 60 minutos com seu time, leitura de três fluxos críticos e um relatório curto indicando gargalos, ganhos esperados e ordem de ataque. Não há compromisso comercial no fim.
Vocês atendem em quais idiomas?
Operamos em pt-BR por padrão. Inglês e espanhol entram como segunda língua em operadores regionalizados. Logs e respostas preservam o idioma do cliente.

06 — Governança

Regras de manutenção

Como novos tokens, variantes e componentes entram na biblioteca sem quebrar a UI Kit.

Fonte de verdade

O CSS em colors_and_type.css é o contrato runtime. A wiki apenas descreve.

  • CSS vence quando diverge da documentação.
  • Toda proposta começa como PR no CSS, nunca em isolamento.

Definição de pronto

Um token entra com nome semântico, valor extraído e comentário de uso.

  • Componente: preview, contrato, índice, README e teste de foco.
  • Alias --color-* sempre apontando para o token base.

Versionamento

SemVer com escopo de design system.

  • Patch para ajuste de valor dentro do token.
  • Minor para novo token, componente ou variante.
  • Major para quebras de API de tokens.

Controle de consistência

Revisão de PR não aprova mudança de design sem diff de tokens.

  • Componentes: atualizar preview, contrato e README no mesmo PR.
  • Tokens: propagar para previews que dependem do token.
